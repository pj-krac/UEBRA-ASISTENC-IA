UEBRA ASISTENCIA V2 SINCRONIZADA

Esta versión usa Supabase como base central.

PASOS RESUMIDOS
1. Crear un proyecto gratuito en Supabase.
2. Abrir SQL Editor y ejecutar supabase_setup.sql.
3. En Project Settings > API copiar Project URL y anon/public key.
4. Pegarlas en config.js.
5. En Authentication > Users crear primero el usuario administrador.
6. Copiar el UUID de ese usuario y ejecutar en SQL Editor:
   insert into profiles(id,nombre,rol) values ('UUID_AQUI','Javier Tinoco Rodas','ADMIN');
7. Subir TODOS estos archivos al repositorio GitHub Pages reemplazando la versión anterior.
8. Iniciar sesión desde el celular.

DOCENTES
Para cada docente: crear usuario en Authentication > Users; luego crear profile DOCENTE y vincularlo a teachers.profile_id.
Ejemplo:
insert into profiles(id,nombre,rol) values ('UUID','Jonathan Daniel Jiménez Rivas','DOCENTE');
update teachers set profile_id='UUID' where nombre='JIMENEZ RIVAS JONATHAN DANIEL';

IMPORTANTE
- Los estudiantes iniciales vienen del listado 2026-2027 ya usado en V1.
- Los retiros NO se borran: se cambia estado.
- Los horarios se administran en la tabla schedules.
- “AIA Cívica y Acompañamiento Integral en el Aula” debe registrarse como “Tutoría”.
- La app guarda una cola local si falla la sincronización; el reintento automático completo se puede añadir en la siguiente iteración.
