Esta versión ya está configurada para conectarse al proyecto Supabase UEBRA Asistencia.

PRUEBA INICIAL
1. Publicar TODOS los archivos de esta carpeta en GitHub Pages, reemplazando los archivos de la versión de prueba cuando corresponda.
2. Abrir la aplicación desde la URL de GitHub Pages.
3. Iniciar sesión con el usuario ADMIN creado en Supabase Authentication.
4. La contraseña NO está incluida en estos archivos.

SEGURIDAD
- config.js contiene únicamente la URL del proyecto y la Publishable key de Supabase.
- No colocar nunca una Secret key ni service_role dentro de la aplicación o GitHub.
- El acceso a los datos depende también de las políticas RLS configuradas en Supabase.

NOTA
El usuario ADMIN ya puede acceder al panel Administrar. Para que el mismo usuario vea además sus clases como docente, su perfil debe vincularse con el registro correspondiente de la tabla teachers.
